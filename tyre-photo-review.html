Tyre Photo Review

Check that each tyre-pressure photo shows the PSI the OE entered. Photos the automatic checks flagged come first, then a random sample. Each verdict takes a few seconds.
How to check: the photo should show the pressure gauge with a lit PSI reading. The large number on top is the measured pressure (the smaller number below is a preset). Tap Matches if it equals the entered PSI, Different if it shows another number (type it in), or Bad photo if it is black, blank, or does not show the gauge with a PSI reading.
